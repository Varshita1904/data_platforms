# 🌊 Data Lake

A **Data Lake** is a centralized storage system that holds **raw data in its original format**.

## What It Stores
- Structured data (tables)
- Semi-structured data (JSON, XML)
- Unstructured data (logs, text, images)
- Streaming data

## Key Characteristics
- Schema on read
- Stores raw data
- Very cheap storage
- Highly scalable

## Where It Lives
- AWS S3
- Azure Data Lake Storage
- Google Cloud Storage

## Why Data Lakes Exist
- Store data first
- Decide how to use it later

## Limitation
- No built-in ACID guarantees
- Can become a data swamp

> **Data Lake = raw, flexible, cheap storage**
